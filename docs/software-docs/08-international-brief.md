## Product and installation
FR is a desktop application for eyewear design. Target packages: Windows x64 EXE, Linux x64 DEB, macOS ARM64 and Intel DMG. There is no mobile or iOS installer. The runtime is bundled; customers do not need development tools. Physical minimum hardware and clean-machine compatibility still require validation. The current interface is Spanish; this brief does not claim full English localization.
Download only a release explicitly marked as verified. Check the publisher, operating system, architecture and SHA-256 manifest signature. Stop if the publisher is unknown or checks fail. Do not disable operating-system protections. Code signing and licensing signatures are separate mechanisms.

## Design and manufacturing
Photos are processed locally. Supported upload formats are JPG, PNG and WebP up to 10 MB. Review the detected outline, crop or trace manually, and calibrate against a known A dimension before applying it. A photograph does not establish depth, lens groove, hinge placement or manufacturing tolerance. Pixel resolution is not a certified accuracy statement.
Use direct nodes and tangent controls for straight, oblique and curved segments. Print at 100 percent and check a known dimension. Validate prototypes, lens fit, hinges, wall thickness and material-specific tolerances before manufacturing. No exact fit with RB2140 or industrial/medical certification is asserted.
